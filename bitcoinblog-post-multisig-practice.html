멀티시그 만들고 되살리기

멀티시그는 말로만 들으면 어렵다. 그래서 지난번에 만든 멀티시그 시뮬레이터로 처음부터 끝까지 직접 굴려 보는 영상을 만들었다. 시드사이너와 크록스, 와치온리 앱(넌척)으로 2-of-2 지갑을 만들고, 전부 지운 뒤 되살리는 과정이다.

연습용 시뮬레이터다. 실제 자산을 보관하는 시드 문구는 입력하지 말 것.

오늘 할 일

  • ① 각 기기에서 시드를 만든다.
  • ② 코디네이터(와치온리 앱)에 두 키를 등록해 2-of-2 지갑을 완성한다.
  • ③ 설계도(디스크립터)를 저장하고, 주소가 맞는지 세 기기에서 확인한다.
  • ④ 돈을 실제로 보내 본다.

④까지 하면 제작은 끝이다. 그다음은 복원 연습이다.

① 시드 만들기

시드사이너에서 Tools → New seed → Dice로 주사위를 굴린다. 시뮬레이터는 연습이라 5번만 굴리지만, 실제로는 50번을 굴려야 한다. 12단어는 종이에만 적고, 마지막에 나오는 지문(fingerprint)도 따로 적어 둔다. 크록스도 New Mnemonic → Via D6로 똑같이 하고, 지갑 종류는 Multisig를 고른다.

② 코디네이터에 등록하기

시드사이너는 Export Xpub → Multisig → Native Segwit, 크록스는 Extended Public Key로 공개키 QR을 띄운다. 넌척 앱의 Keys → ＋ → Generic Airgap으로 두 QR을 차례로 스캔한 뒤, Custom wallet에서 두 키를 고르고 필요한 서명 수를 2로 올리면 2/2 멀티시그 지갑이 완성된다. 공개키라서 보여 줘도 돈은 안전하다.

③ 설계도 저장과 주소 확인

가장 중요한 단계다. 멀티시그는 시드 단어만으로는 되살릴 수 없다. 어떤 키 몇 개가 서명하는지 적힌 지갑 설정, 즉 디스크립터가 있어야 같은 주소를 다시 만들 수 있다. 앱에서 이 파일(BSMS)을 저장해 두고, 앱·시드사이너·크록스에서 첫 번째 받는 주소를 띄워 글자 하나까지 같은지 비교한다.

④ 돈 보내 보기

앱에서 거래를 만들어 QR로 띄우면, 시드사이너가 받는 주소·금액·잔돈을 보여 준다. 앱과 같은지 눈으로 확인하고 서명하면 1/2. 크록스로도 서명하면 2/2가 되고, 그제야 전송 버튼이 나타난다. 기기 하나만으로는 돈이 움직이지 않는다.

복원 연습

시드사이너와 크록스는 전원을 끄면 시드가 사라지고(스테이트리스), 앱도 새 폰처럼 비운다. 종이에 적은 12단어를 다시 넣으면 처음과 같은 지문이 떠야 한다. 단어 하나만 틀려도 지문이 완전히 달라지니, 적어 둔 지문과 꼭 비교한다. 마지막으로 앱에서 Recover existing wallet → Import via file로 백업해 둔 디스크립터를 고르면 지갑이 돌아오고, 첫 주소도 처음과 똑같다.

정리

시드 단어는 종이에, 지문은 따로 적고, 디스크립터 파일은 여러 벌 보관하기. 진짜 돈을 넣기 전에 시뮬레이터로 몇 번이고 굴려 보길 권한다.
