# Perplexity

- 유형: 웹사이트/앱(AI 답변 검색엔진) / 제작자: Perplexity AI(CEO 아라빈드 스리니바스) / 공개 시기: 2022년 / 사용한 AI: 여러 외부 LLM(OpenAI, Anthropic 등)과 자체 튜닝 모델 / 링크: https://www.perplexity.ai

## 어떤 작품인가
질문을 하면 웹을 검색해서 여러 출처를 읽고, 출처 번호가 달린 답을 한 문단으로 정리해 주는 "답변 엔진"이에요. 링크 10개를 주는 기존 검색 대신 바로 답을 주되, 어디서 가져왔는지 각주로 보여주는 게 특징이에요. 자체 기초 모델 회사가 아니라 남의 LLM 위에 검색을 결합해서 성공한 대표적인 제3자 서비스예요.

## 왜 평가가 좋은가
- CEO가 블룸버그 테크 서밋에서 2025년 5월 한 달 쿼리 7억 8천만 건, 월 20% 넘는 성장이라고 밝혔어요(TechCrunch 보도 인용, 2025-06-05). 2022년 첫날엔 3천 건이었대요.
- 2025년 9월 2억 달러를 투자받으며 기업가치 200억 달러로 평가됐다는 보도(The Information 인용, Seeking Alpha 등).

## AI를 어떻게 썼나
검색으로 최신 웹 문서를 가져온 뒤 LLM이 그걸 읽고 요약하게 하는 RAG(검색 증강 생성) 구조예요. 유료 사용자는 답변에 쓸 모델을 고를 수 있어요.

## 생각해볼 점
언론사들이 "기사를 가져가 요약만 하고 트래픽은 안 준다"며 반발해 왔어요. 출처를 보여준다고 해서 요약이 정확하다는 보장도 없으니, 중요한 건 각주 링크를 직접 열어보는 습관이 필요해요.
