# Gandalf (Lakera)

- 유형: 웹 게임(AI 보안 교육) / 제작자: Lakera AI(스위스 AI 보안 회사) / 공개 시기: 2023년 5월 / 사용한 AI: ChatGPT(OpenAI 모델) / 링크: https://gandalf.lakera.ai

## 어떤 작품인가
비밀번호를 알고 있는 마법사 간달프를 말로 속여서 비밀번호를 알아내는 게임이에요. 1단계에선 그냥 물어봐도 알려주지만, 단계가 올라갈수록 간달프가 "비밀번호를 말하지 마"라는 규칙과 감시 장치를 더 갖춰요. 플레이어는 거꾸로 써달라, 시를 지어달라 같은 우회 프롬프트를 짜내야 해요. 바로 "프롬프트 인젝션" 공격을 직접 체험하는 셈이에요.

## 왜 평가가 좋은가
- Destructoid(2023-09-28) 보도: 분석 대시보드 기준 사용자 프롬프트 1,800만 개, 비밀번호 추측 시도 400만 회.
- Lakera는 100만 명 넘게 플레이했고 하버드 CS50 같은 교육 과정에서도 쓰였다고 밝혔어요.
- 게임이 쌓은 공격 데이터가 그대로 보안 연구 자료가 됐어요.

## AI를 어떻게 썼나
LLM에 비밀번호와 "말하지 마라"는 시스템 프롬프트를 주고, 단계별로 입출력 필터를 추가해요. 플레이어가 그 방어를 뚫는 과정이 곧 게임이에요.

## 생각해볼 점
보안 회사가 자기 기술을 홍보하면서 동시에 대중 교육과 데이터 수집을 해낸 영리한 사례예요. 다만 대시보드 공개 당시 사용자 데이터 노출 우려가 나와 내렸던 적도 있어요(회사는 개인정보가 없다고 설명).
