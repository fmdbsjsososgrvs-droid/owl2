# Cursor

- 유형: 앱(AI 코드 에디터) / 제작자: Anysphere(마이클 트루얼, 아만 생어, 아르비드 루나마크, 수알레 아시프) / 공개 시기: 2022년 창업 / 사용한 AI: 외부 LLM(Claude, GPT 계열 등)과 자체 모델 / 링크: https://cursor.com

## 어떤 작품인가
VS Code를 기반으로 만든 코드 편집기인데, 처음부터 AI랑 같이 코딩하는 걸 전제로 설계했어요. 코드베이스 전체를 이해한 상태로 질문에 답하고, 여러 파일을 한 번에 고치고, 다음에 칠 코드를 예측해서 탭 한 번으로 채워줘요. "LLM 위에 얹은 제3자 제품"이 얼마나 커질 수 있는지 보여준 대표 사례예요.

## 왜 평가가 좋은가
- Trending Topics(2026-03-03) 보도: 연 반복매출(ARR) 20억 달러 돌파, 최근 3개월 사이 매출 두 배.
- 같은 보도 기준 2025년 11월 투자 라운드에서 기업가치 293억 달러.
- 매출의 약 60%가 기업 고객에서 나온다고 해요. 개발자 개인 도구에서 회사 표준 도구로 넘어갔다는 뜻이죠.

## AI를 어떻게 썼나
여러 회사의 최신 LLM을 골라 쓸 수 있게 하고, 자동완성 같은 빠른 작업엔 자체 모델을 써요. 핵심은 모델 자체보다 "코드베이스를 어떻게 잘라서 모델에 보여줄지"를 잘 설계한 데 있어요.

## 생각해볼 점
같은 보도에서 Claude Code 같은 경쟁 도구로 개발자가 옮겨간다는 논의도 언급됐어요. 모델 회사가 직접 도구를 내놓을 때, 그 위에 지은 제품이 어떻게 살아남는지가 계속 숙제예요.
