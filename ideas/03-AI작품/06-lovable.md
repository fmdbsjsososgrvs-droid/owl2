# Lovable

- 유형: 서비스(대화로 앱 만드는 AI 빌더) / 제작자: Lovable(스웨덴 스톡홀름, 안톤 오시카·파비안 헤딘) / 공개 시기: 2024년 11월 / 사용한 AI: Anthropic Claude(Sonnet 3.5, Opus 4.5 등) / 링크: https://lovable.dev

## 어떤 작품인가
"이런 앱 만들어줘"라고 말로 설명하면 화면, 데이터베이스, 로그인까지 갖춘 웹앱을 만들어 주는 서비스예요. 이른바 "바이브 코딩" 붐을 대표하는 제품이고, 코딩을 못 하는 99%를 위한 도구라는 걸 내세워요.

## 왜 평가가 좋은가
- 출시 약 8개월 만에 ARR 1억 달러 돌파, "가장 빨리 성장한 소프트웨어 회사"로 보도(Sifted, Indie Hackers 등, 2025년).
- Anthropic 고객 사례(2026-10-05 확인): 출시 12개월에 ARR 2억 달러, 이후 4억 달러. 누적 프로젝트 5천만 개 이상, 하루 20만 개 넘게 새로 만들어지고, Lovable로 만든 앱들의 월 방문은 6억 회 이상.
- 마이크로소프트, 우버, 허브스팟 같은 기업도 쓴다고 해요.

## AI를 어떻게 썼나
Claude가 여러 파일에 걸친 코드를 쓰고 고치는 "에이전트" 역할을 해요. 제품 담당자는 Claude Sonnet 3.5가 처음으로 에이전트를 제대로 작동하게 만든 모델이었다고 말했어요.

## 생각해볼 점
누구나 앱을 만들 수 있게 된 건 큰 변화지만, 만든 사람이 코드를 이해 못 하면 보안 구멍이나 유지보수 문제가 남아요. 그리고 Anthropic이 비슷한 기능을 직접 만든다는 보도도 있어서 플랫폼 의존 위험이 있어요.
